# Miaojy 的每日研究任务

每天 08:00（Asia/Shanghai）在 GitHub 仓库 `JimmyKudo123433/miaojy-research-library` 中运行。目标研究方向是**复杂越野环境下 Segway 式智能无人小车的横向稳定控制**。以中文撰写 Quick Read 和论文详情，保留常见英文术语、缩写和论文原文摘要。

## 每次运行

1. 读取 `config/research-profile.yaml`，检查 `data/papers/`、`data/daily/` 和 `data/user/`。每次最多新增或推荐一篇论文。
2. 检索两轮倒立摆/Segway 式车辆在以下主题中的新研究：横向侧倾/横滚稳定、越野地形建模、轮地接触与轮荷转移、地形适应、低附着与抗滑、越障/侧坡稳定、自适应/鲁棒/MPC 控制。兼顾直接相关的新论文和必要的高价值基础论文。
3. 优先使用出版方页面、论文 PDF/官方 HTML、DOI/Crossref、arXiv 或 OpenReview 等可核验来源。逐一核实题名、作者、年份、期刊/会议、DOI/预印本编号和论文链接。CCF、CAS、JCR 等排名没有可靠来源时写 `null`，不得猜测。
4. 对照既有 DOI、arXiv/OpenReview 编号和规范化题名查重。若没有新论文达到质量与相关性要求，选择一篇尚未精读且今天未推荐的高价值论文；若没有合适条目则不新增，并说明原因。
5. Quick Read 可以先依据摘要和元数据起草。论文详情应尽量读取公开全文，覆盖 Introduction/Motivation、Method、Experiments/Results 和 Limitations/Discussion；为贡献、研究问题和关键结果记录章节、页码、表格或图号。只有合理尝试获取全文仍失败时，才用 `abstract_only`，必须在阅读依据和限制中说明，不能编造正文结论。
6. 对全文/官方 HTML 论文阅读 Introduction/Motivation 后提取作者明确提出的问题；没有显式 RQ 编号但研究目标可可靠概括时，记录标为 `inferred` 的研究问题并附引言定位。只有确实无法可靠提取时才留空，并按数据 schema 填写空因说明和定位。
7. 详细报告需包含 2–5 项具体贡献，以及至少 3 个针对本文方法、实验或局限提出的后续研究方向。每个方向写清理由、计划、验证方式和预期价值。区分作者报告事实与自己的分析。
8. 将规范化论文记录写入 `data/papers/<paper-id>.json`，初始化 `data/user/<paper-id>.json`，并更新当天 `data/daily/YYYY-MM-DD.json`。保留已有个人笔记、标签、收藏和阅读状态。使用仓库现有 schema，不改前端结构来绕过校验。
9. 检查所有文件引用和 JSON 结构，提交一个清晰、原子化的 commit 并推送到 `main`。随后等待 GitHub Actions 中 Pages 部署工作流完成；只有数据校验、构建和部署均成功后才报告已发布。若权限不足、Actions 失败或仓库无法写入，要准确说明状态，不声称已经提交或部署。

## 相关性判断

**High**：直接研究两轮自平衡/倒立摆车辆在越野、坡地、松散或低附着环境中的侧倾、横滚、抗侧翻、横向姿态、轮荷转移或轮地稳定控制。

**Medium**：研究 Segway/TWIP 的鲁棒平衡、地形适应、抗滑、越障或状态估计，但未直接处理横向稳定；或者研究可迁移的轮式越野平台控制方法。

**Low**：只在平地讨论一般两轮机器人控制，或与本方向仅有宽泛关键词重合。除非其基础价值非常明确，否则不收录。

每天输出简短中文结果：是否新增/复用论文、证据阅读范围、推荐理由、提交链接，以及 Pages 工作流结果和网站链接。
